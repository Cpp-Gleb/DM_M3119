# Практическое задание: производящие функции на Prolog

## Цель задания

Нужно написать небольшую библиотеку на **Prolog** для работы с обыкновенными производящими функциями и применить её к простым комбинаторным задачам.

Производящая функция последовательности

$$
 a_0, a_1, a_2, \dots
$$

имеет вид:

$$
 A(x)=a_0+a_1x+a_2x^2+\dots
$$

В этом задании производящую функцию будем хранить как список коэффициентов:

```prolog
[1, 2, 3, 4]
```

Это означает:

$$
1+2x+3x^2+4x^3.
$$

То есть элемент списка с индексом `N` — это коэффициент при `x^N`.

---

## Что нужно реализовать

Создайте файл:

```text
gf.pl
```

В нём нужно реализовать модуль:

```prolog
:- module(gf, [
    gf_coeff/3,
    gf_add/3,
    gf_scalar_mul/3,
    gf_shift/3,
    gf_mul/3,
    gf_prefix_sums/2,
    gf_range/3,
    gf_count_sum/3,
    catalan/2
]).
```

---

## 1. Получение коэффициента

### Предикат

```prolog
gf_coeff(+GF, +Degree, -Coeff).
```

### Что делает

Возвращает коэффициент при `x^Degree`.

Если степень больше длины списка, коэффициент считается равным `0`.

### Пример

```prolog
?- gf_coeff([3, 0, 8, 1], 2, C).
C = 8.

?- gf_coeff([3, 0, 8, 1], 10, C).
C = 0.
```

---

## 2. Сложение производящих функций

### Предикат

```prolog
gf_add(+A, +B, -Result).
```

### Что делает

Складывает две производящие функции покоэффициентно.

### Пример

```prolog
?- gf_add([1, 2, 3], [10, 20], R).
R = [11, 22, 3].
```

Пояснение:

$$
(1+2x+3x^2)+(10+20x)=11+22x+3x^2.
$$

---

## 3. Умножение на число

### Предикат

```prolog
gf_scalar_mul(+Scalar, +GF, -Result).
```

### Что делает

Умножает все коэффициенты производящей функции на число.

### Пример

```prolog
?- gf_scalar_mul(3, [1, 2, 3], R).
R = [3, 6, 9].
```

---

## 4. Сдвиг вправо

### Предикат

```prolog
gf_shift(+GF, +K, -Result).
```

### Что делает

Умножает производящую функцию на `x^K`, то есть добавляет `K` нулей в начало списка.

### Пример

```prolog
?- gf_shift([1, 2, 3], 2, R).
R = [0, 0, 1, 2, 3].
```

Пояснение:

$$
1+2x+3x^2 \quad \mapsto \quad x^2+2x^3+3x^4.
$$

---

## 5. Умножение производящих функций

### Предикат

```prolog
gf_mul(+A, +B, -Result).
```

### Что делает

Перемножает две производящие функции по правилу свёртки:

$$
 c_n = a_0b_n+a_1b_{n-1}+\dots+a_nb_0.
$$

### Пример

```prolog
?- gf_mul([1, 1], [1, 1, 1], R).
R = [1, 2, 2, 1].
```

Пояснение:

$$
(1+x)(1+x+x^2)=1+2x+2x^2+x^3.
$$

---

## 6. Производящая функция префиксных сумм

### Предикат

```prolog
gf_prefix_sums(+GF, -Result).
```

### Что делает

Для последовательности коэффициентов

```text
a0, a1, a2, ...
```

строит последовательность префиксных сумм:

```text
s0, s1, s2, ...
```

где:

$$
 s_n=a_0+a_1+\dots+a_n.
$$

### Пример

```prolog
?- gf_prefix_sums([1, 2, 3, 4], R).
R = [1, 3, 6, 10].
```

---

## 7. Производящая функция диапазона

### Предикат

```prolog
gf_range(+Low, +High, -GF).
```

### Что делает

Строит производящую функцию для переменной, которая может принимать значения от `Low` до `High` включительно.

То есть:

$$
 x^{Low}+x^{Low+1}+\dots+x^{High}.
$$

### Пример

```prolog
?- gf_range(2, 5, GF).
GF = [0, 0, 1, 1, 1, 1].
```

Пояснение:

$$
x^2+x^3+x^4+x^5.
$$

---

## 8. Подсчёт количества решений уравнения

### Предикат

```prolog
gf_count_sum(+Bounds, +Sum, -Count).
```

### Что делает

Считает количество целочисленных решений уравнения:

$$
 x_1+x_2+\dots+x_k=Sum,
$$

если для каждой переменной заданы границы.

Формат границ:

```prolog
[Low-High, Low-High, ...]
```

### Пример

```prolog
?- gf_count_sum([0-4, 0-4, 0-4], 8, Count).
Count = 15.
```

Это соответствует задаче:

$$
 x_1+x_2+x_3=8,
$$

где:

$$
0\le x_1,x_2,x_3\le 4.
$$

---

## 9. Числа Каталана

### Предикат

```prolog
catalan(+N, -C).
```

### Что делает

Вычисляет число Каталана:

$$
 C_n=\frac{1}{n+1}\binom{2n}{n}.
$$

Числа Каталана считают, например, количество правильных скобочных последовательностей из `N` пар скобок.

### Примеры

```prolog
?- catalan(0, C).
C = 1.

?- catalan(3, C).
C = 5.

?- catalan(6, C).
C = 132.
```

## Требования к реализации

1. Код должен быть написан на **SWI-Prolog**.
2. Нельзя просто захардкодить ответы под тесты. Тестов будет больше чем вам дано.
3. Предикаты должны работать не только на примерах из README.
4. Индексация коэффициентов начинается с нуля.
5. Входные списки коэффициентов считаются конечными производящими функциями.
6. Если коэффициент за пределами списка, он считается равным `0`.
7. Желательно удалять лишние нули в конце результата, но это не обязательно, если тесты математически эквивалентны.
8. Решение должно быть достаточно универсальным: скрытые тесты будут проверять разные длины списков и разные границы.

Скрытые тесты будут проверять:

1. сложение списков разной длины;
2. умножение многочленов разной степени;
3. получение коэффициентов за пределами списка;
4. сдвиги на разные значения `K`;
5. построение функций диапазонов;
6. подсчёт количества решений для разных систем ограничений;
7. числа Каталана для разных `N`;
8. отсутствие хардкода под конкретные примеры.
